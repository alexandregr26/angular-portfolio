PROJECT SHOWCASE

FPS Game

A RETRO RAY-TRACED EXPERIMENT IN LOW-LEVEL GAME DEVELOPMENT

A first-person shooter built from the ground up in C for the Altera DE1-SoC board. The game renders a 3D maze-like environment from a 2D map using a lightweight ray-tracing approach, with player movement, collision detection, enemy sprites, fireballs, and VGA output all handled directly through low-level hardware interaction.

Source code available on request.

This project is hosted in a private repository to support academic integrity.

OVERVIEW

Developed for the University of Toronto's second-year Computer Engineering course, Computer Organization (ECE243), this project was my first complete game development experience and an introduction to graphics programming. The game uses a ray-based rendering system to project a simple 2D map into a first-person 3D view, drawing walls, floors, enemies, and projectiles in real time.

The project was designed specifically for the Altera DE1-SoC board, using memory-mapped I/O to read hardware switches and push buttons, drive LED feedback, and render directly to the VGA pixel buffer. Beyond the visual renderer, the game includes player navigation, wall collision handling, sprite-based enemies, projectile firing, depth-based occlusion, and double-buffered rendering for smoother gameplay.

Ray-Traced Rendering

The game renders its 3D view by casting rays across the player’s field of view and stepping each ray forward until it reaches a wall or exceeds the visible depth range. The measured distance is then used to determine the height and shade of each wall column, creating a first-person perspective from a 16x16 map.

DE1-SoC Controls

Player input is mapped directly to the board's physical switches and push buttons. The switches control movement, rotation, and strafing, while push buttons handle shooting and game-state actions.

Gameplay Objects

The game includes two main object types: enemy sprites and fireball projectiles. Both types of objects are updated every frame, checked against the map for wall collisions, projected into screen space, and drawn only when they fall inside the player’s field of view.

VGA Rendering & Performance

The game outputs directly to a VGA display and is optimized to run reliably within the limited resources of the DE1-SoC platform. The final result is intentionally minimal, but technically complete: a playable FPS-style renderer built close to the hardware.

Arcade Influence

Inspired by early arcade shooters, this project captures the spirit of building a game from limited resources. The visuals are simple and the controls hardware-driven, but the project brings together the essential parts of an FPS: movement, perspective, enemies, collision, and real-time display.
