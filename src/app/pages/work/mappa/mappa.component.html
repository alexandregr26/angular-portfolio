PROJECT SHOWCASE

Mappa

Intuitive. Exploratory. Geospatial.

A lightweight geographic information system (GIS) application that helps users search for locations, compute optimal routes, and visualize spatial data with an interactive and fully customizable map experience.

{{ item }}

OVERVIEW

Mappa is a desktop GIS application built in C++ with the OpenStreetMap API and EZGL graphics library, allowing users to load and interact with global city maps in real time. The project was designed around the challenge of turning complex geographic data into an experience that feels clear, responsive, and easy to control. Through efficient map rendering, intuitive search, route-finding, and customizable visual layers, Mappa makes spatial information more accessible without sacrificing performance or usability.

ENGINEERING CONTEXT

This project was developed as part of a collaborative second-year engineering course, ECE297, at the University of Toronto. The course gave students the opportunity to design, build, and iterate on a complex software system from the ground up, applying core concepts in data structures, algorithms, graphics, and software design.
